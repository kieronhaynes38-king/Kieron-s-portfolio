# Scholarship Robot Autofill Extension

This unpacked Chrome/Edge extension fills verified contact, address, education,
GPA, and public-link fields on scholarship application pages. It never clicks
Submit and skips passwords, SSNs, financial accounts, tax/FAFSA data,
signatures, certifications, recommendations, file uploads, radios, and consent
checkboxes.

## Install

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose `Load unpacked`.
4. Select this `extension` folder.
5. Open the extension and import `config/private-profile.json`.

The profile is stored only in the selected browser profile's extension storage.
